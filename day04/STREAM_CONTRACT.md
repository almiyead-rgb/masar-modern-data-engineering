<table dir="ltr" width="100%"><tr><td width="50%" dir="ltr" lang="en" align="left" valign="top"><h2>Two keys and two row meanings</h2><p><strong>Transport row:</strong> one received Kafka message position, uniquely identified by <code>(topic, partition, offset)</code>.<br><strong>Business event:</strong> one observation identified by <code>event_id</code>.</p><p>Raw Bronze preserves intentional repeated observations at new transport positions. Compare event payloads before business deduplication: one event ID with conflicting content is an error, not permission to choose an arbitrary row.</p></td><td width="50%" dir="rtl" lang="ar" align="right" valign="top"><h2>مفتاحان ومعنيان للصف</h2><p><strong>صف النقل:</strong> موضع رسالة Kafka مستقبلة، يحدده <code>(topic, partition, offset)</code> بصورة فريدة.<br><strong>حدث الأعمال:</strong> ملاحظة واحدة يحددها <code>event_id</code>.</p><p>تحفظ Bronze الخام الملاحظات المعاد إرسالها عمدًا في مواضع وصول جديدة. قارن المحتوى قبل إزالة تكرار الأعمال؛ اختلاف المحتوى مع معرف حدث واحد خطأ، لا إذن لاختيار صف عشوائي.</p></td></tr></table>

<table dir="ltr" width="100%"><tr><td width="50%" dir="ltr" lang="en" align="left" valign="top"><h2>Payload fields</h2><p><code>event_id</code>: non-empty string.<br><code>trip_id</code>: a trip in corrected Silver.<br><code>event_ts</code>: parseable ISO timestamp with an explicit timezone.<br><code>city</code>: Riyadh, Jeddah or Dammam.<br><code>location</code>: finite numeric latitude in [-90, 90] and longitude in [-180, 180].<br><code>synthetic</code>: exactly true.</p><p>The fixed source contract accepts only these payload fields and <code>lat</code>/<code>lon</code> inside location. The code checks the fixed sources and reconciles received contents against them. Broker headers and ingestion metadata belong to the receipt envelope, not the event payload.</p></td><td width="50%" dir="rtl" lang="ar" align="right" valign="top"><h2>حقول محتوى الحدث</h2><p><code>event_id</code>: نص غير فارغ.<br><code>trip_id</code>: رحلة موجودة في Silver المصححة.<br><code>event_ts</code>: توقيت ISO قابل للقراءة مع منطقة زمنية صريحة.<br><code>city</code>: Riyadh أو Jeddah أو Dammam.<br><code>location</code>: خط عرض عددي محدود ضمن [-90، 90] وخط طول ضمن [-180، 180].<br><code>synthetic</code>: القيمة true تحديدًا.</p><p>يقبل عقد المصادر الثابتة هذه الحقول فقط و<code>lat</code> و<code>lon</code> داخل الموقع. يفحص الكود المصادر ويطابق المحتوى المستقبَل معها. ترويسات الوسيط وبيانات الاستقبال تخص سجل الوصول، لا محتوى الحدث.</p></td></tr></table>

Do not share that checkpoint between unrelated queries.</p><p>A sending intent is retained before publication; a partial send is not automatically resent. Keep original Kafka topic data and compatible checkpoint/destination together for resume.
